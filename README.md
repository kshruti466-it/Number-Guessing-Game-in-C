# Number Guessing Game in C

A simple number guessing game made using C language.

## Features
- Random number generation
- Higher / Lower hints
- Guess counter

## How to Run

1. Clone the repository:

git clone https://github.com/kshruti466-it/number-guessing-game-c.git

2. Open the folder.

3. Compile the code:

gcc 1_Game.c -o game

4. Run the program:

./game

## Example

Guess the number between 1 to 100
50
Higher number please
75
Lower number please
63
Correct! You guessed it!
